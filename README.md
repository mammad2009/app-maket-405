# Peugeot405Control (v2.0)

برنامه‌ی کنترل ماکت پنوماتیک پژو ۴۰۵ از طریق بلوتوث (HC-05) — دو زبانه (فارسی / English).

## مراحل برنامه
1. **صفحه‌ی شروع** – آرم شیر پژو با برق نور، بعد اسم PEUGEOT و آرم «405 GLX». (با یک لمس رد می‌شود)
2. **صفحه‌ی اتصال** – یک دکمه‌ی اتصال به HC-05.
3. **ریموت پژو** – قفل `K` / باز `U`؛ بعد از «باز» می‌رود داخل منو.
4. **منو** – سه بخش در نوار پایین:
   - **کنترل**: جلو / عقب / هر دو، میباخ، ارتفاع فابریک، **حالت نمایشگاهی** و آرم شیر (به جای عکس ماشین).
   - **کارخانه**: با ورود به این بخش فرمان `Y` فرستاده می‌شود (ماکت کف‌خواب + صحنه‌ی کارخانه روی OLED)،
     با خروج از بخش یا بستن برنامه فرمان `V` (ماکت با افکت بامزه بیدار می‌شود).
   - **فرمان‌ها**: انتخاب زبان، ویرایش و ارسال فرمان‌ها.
5. تغییر سریع زبان: دکمه‌ی `EN` / `فا` بالای صفحه.

## فرمان‌های جدید (هماهنگ با car_emo_eyes_v21_esp8266.ino)
| کار | فرمان |
|---|---|
| ورود به حالت کارخانه | `Y` |
| خروج از حالت کارخانه | `V` |
| شروع نمایشگاهی | `S` |
| توقف نمایشگاهی | `E` |

اگر در کد ماکت `ENABLE_BATTERY` را 1 کنی، ماکت هر ۵ ثانیه `BAT:87` می‌فرستد و درصد باتری بالای صفحه نشان داده می‌شود.

فرمان‌های قبلی (`F B R L 1 2 X Z M N K U 0`) بدون تغییر هستند و همه از «فرمان‌ها» قابل ویرایش‌اند.
