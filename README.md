# Peugeot 405 Control

Steps (فارسی):
1. این پوشه را کامل توی یک ریپازیتوری گیت‌هاب بریز (www ، config.xml ، package.json ، .github).
2. برو تب Actions ← Build APK ← Run workflow (یا با هر push خودش اجرا میشه).
3. بعد از ۵ تا ۱۰ دقیقه، پایین صفحه‌ی اجرا در بخش Artifacts فایل peugeot405-apk رو دانلود کن.
4. فایل apk رو نصب کن ، اول HC-05 رو توی تنظیمات بلوتوث گوشی جفت کن (رمز 1234 یا 0000) ، بعد برنامه رو باز کن.

لوگوی خودت: فایل logo.svg یا logo.png رو کنار www/index.html بذار (اگه svg باشه خودش جایگزین آرم میشه).
