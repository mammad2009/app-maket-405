# Peugeot 405 Private Garage — نسخه‌ی شروع

اپ اندروید دوزبانه‌ی فارسی/انگلیسی برای کنترل ماکت پژو ۴۰۵ با ESP8266 و ماژول بلوتوث کلاسیک HC-05.

## ساخت APK با GitHub
1. یک مخزن جدید در GitHub بساز و محتویات این پوشه را در آن آپلود کن.
2. به تب **Actions** برو و workflow با نام **Build Peugeot 405 APK** را اجرا کن (یا یک commit بزن).
3. بعد از پایان موفق workflow، از بخش Artifacts فایل `Peugeot405Remote-debug-apk` را دانلود کن.
4. فایل APK را روی گوشی نصب کن. این خروجی debug است و برای انتشار رسمی فروشگاهی امضا نشده است.

## اتصال
- ابتدا از تنظیمات Bluetooth اندروید، HC-05 را Pair کن (معمولاً PIN ماژول 1234 یا 0000 است؛ مقدار واقعی ماژول خودت ملاک است).
- اپ را باز کن و Connect Bluetooth HC-05 را بزن.
- این نسخه از Bluetooth Classic SPP استفاده می‌کند، نه BLE.

## فرمان‌های پیاده‌سازی‌شده
تعلیق: `F` جلو بالا، `B` جلو پایین، `R` عقب بالا، `L` عقب پایین، `W` هر دو بالا، `D` هر دو پایین، `1`/`2` جلو به دو انتها، `X`/`Z` عقب به دو انتها.
چراغ‌ها مطابق `lightsCmd()` در فایل ino نگاشت شده‌اند. `M` حالت نمایشی MAYBACH، `N` پایان آن، `T` گردش صحنه‌های نمایشگر، `K` قفل و `U` بازکردن است.

## نکته‌های مهم
- این پروژه یک **نسخه‌ی اولیه‌ی قابل توسعه** است؛ UI با الهام از هویت قرمز/مشکی لوگوی فرستاده‌شده طراحی شده و از اسکرین‌شات‌های مرجع کپی نشده.
- اتصال واقعی فقط وقتی کار می‌کند که سیم‌کشی و firmware با همین فرمان‌های تک‌کاراکتری هماهنگ باشد.
- `holdButton` در نسخه‌ی فعلی برای محور جلو/عقب فرمان حرکت را با لمس می‌فرستد؛ برای کنترل دقیق‌تر توقف با رهاکردن و محدودسازی نرخ ارسال، قبل از استفاده‌ی طولانی باید روی سخت‌افزار واقعی آزمایش شود.
- عکس لوگوی ارسالی داخل `app/src/main/res/drawable/peugeot405_logo.png` قرار گرفته است.


## Workflow اصلاح‌شده
فایل `.github/workflows/main.yml` شامل مرحله‌ی `android-actions/setup-android@v3` است تا ابزار `sdkmanager` پیش از نصب پکیج‌ها روی PATH قرار بگیرد. این نسخه خطای قبلی `sdkmanager: command not found` را هدف می‌گیرد.
